## Public Copy Guardrails

- Do not include design-style names, reference brands, path-validation notes, or prototype caveats in website copy.
- Convert internal stage names into customer-facing labels before implementation.
- Keep product capabilities, solution scenarios, service workflow, and CTAs concrete.
- Run name normalization across visible text, metadata, alt text, SVG text, and accessibility labels.
