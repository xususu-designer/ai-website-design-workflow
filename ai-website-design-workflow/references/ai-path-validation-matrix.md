## Suggested Paths

| Path | What AI Does | What Designer Judges | Best For | Common Failure |
| --- | --- | --- | --- | --- |
| Prompt to HTML | Generates runnable page quickly | Structure, brand fit, visual quality | Fast prototype and motion check | Rough visuals, unstable hierarchy |
| Prompt to image | Generates visual page mockups | Mood, composition, visual ideas | Visual exploration | Not editable, hard to implement |
| Reference image/site generation | Mimics reference style | Whether it copies or abstracts principles | Extracting atmosphere | Over-copying or weak relation |
| Mature DESIGN.md reference | Uses mature design rules | Fit to project and brand | Layout, spacing, component discipline | Template feel |
| Style skill generation | Applies a selected design style | Whether style supports the brief | Exploring varied directions | Inconsistent controllability |
| Manual design + AI coding | AI assists elements, HTML, CSS, motion | Final structure, visual system, quality | Most controllable delivery | Higher design effort |
| AI direction -> Figma deepening -> web implementation | AI creates direction evidence; designer refines in Figma; Codex implements final design | Direction usefulness, Figma fidelity, implementation feasibility | Real design workflow with human visual control | Requires clean handoff and design inspection |
| Figma-to-code / no-code builder | Translates design or prompt into editable page | Fidelity, responsiveness, maintainability | Handoff and stakeholder preview | Hidden constraints or brittle output |
